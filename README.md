# AHP Frontend

## 🚀 Technologies Used
- Typescript  
- React  
- Tailwind CSS  
- MUI  
- Axios  

## ✨ Features
- Landing page  
- Input matrices  
- Matrix calculation  
- Display results in table format  
- Visualize results with charts  
- View history of calculated matrices  
- Export matrix data
